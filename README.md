# 5005-timeline-sketch

Roadmap sketch for the PHM5005 SkinProfile project (face-scan skin analysis tool). It is a single flowchart, read left to right.

Live page: https://charlesyapai.github.io/5005-timeline-sketch/

## Files

- `index.html` - the page served by GitHub Pages (scrollable chart with zoom buttons)
- `roadmap.svg` - standalone vector version, importable into PowerPoint
- `roadmap.md` - short status note linking to the SVG

## Updating

Regenerate the SVG with the freeform-flowchart skill, drop the new files here, commit and push to `main`. Pages rebuilds automatically.

## Notes

This will be ported to a Hugging Face Space later. No data or model weights live in this repo.
